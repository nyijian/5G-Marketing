# 5G定制网招标信息监测工具

这是一个可在本地运行的5G定制网、5G行业专网采购机会监测工具。当前展示范围锁定为**四川省**，默认日期窗口由[`config/scope.json`](config/scope.json)控制：**从2026-01-01采集至运行时点（北京时间）**。

当前链路：

> 多来源官方检索 → 公告详情/正文 → 四川范围复核 → 相关性判断 → SQLite去重入库 → 跨平台合并 → Excel导出

## 招标发布平台与线索站点

只有**招标发布平台、公共资源平台或集团电子采购平台**才计入信息源覆盖。采购人官网、第三方聚合站、Bing和固定验证种子都不计入平台数量。

当前`pnpm collect`实际自动采集7个平台：

1. **中国政府采购网**：地区代码51；全文索引覆盖标题和正文。
2. **四川政府采购网**：四川地方预算单位政府采购信息的省级分网；标题检索并读取详情。
3. **全国公共资源交易平台**：地区代码510000；读取公开交易接口和详情。
4. **四川省公共资源交易信息网**：四川依法必须招标项目的省指定媒介；读取四川站检索和原文。
5. **中国电信阳光采购网**：覆盖集团四川、终端四川和集成四川。
6. **天府阳光采购服务平台**：已接入，当前环境受IP/滑块限制。
7. **四川能源天府阳光采购服务平台**：已接入，当前环境受IP/滑块限制。

已经验证、适合下一步接入的平台包括：四川港投交易平台、国投集团电子采购平台、鞍钢智慧招投标平台、东方电气采购管理平台和四川招投标网。四川招投标网属于市场化信息发布/交易平台，不是当前政府指定媒介。

大唐智慧寻源、国家电网ECP、西南联交所、中国移动、中国联通、中国铁塔、成都高投和四川大学招投标与采购中心属于受限或待评估平台。完整平台台账见[`config/source-catalog.json`](config/source-catalog.json)。该文件现在只保留真正的平台。

医院、卫健委和集团新闻栏目已移至[`config/verification-sites.json`](config/verification-sites.json)，统一标为`buyer_site / verification_only`，只用于原文核验和反查平台，不计入采集覆盖。目前核对的院内5G项目多数低于四川政府采购限额，未发现同步平台；这类项目不能凭空指定一个“对应平台”。

规则依据：地方预算单位正式政府采购信息应发布在中国政府采购网省级分网；四川货物、服务类分散采购限额为省级及成都市本级50万元，其他市本级和县级30万元。依法必须招标的四川项目应至少在四川省公共资源交易信息网发布。低于限额、按单位内控制度实施的院内询价或比选，可能只有采购人官网原文。

参考依据：财政部《政府采购信息发布管理办法》（财政部令第101号）、《四川省政府集中采购目录及标准（2024年版）》及《四川省招标投标信息公开办法》。

## 关键词与判断规则

当前实际检索[`config/keywords.json`](config/keywords.json)中的35个关键词。首轮19个词继续保留，本轮补充了16个场景词：

`5G网络传输`、`5G智慧医学影像`、`5G智慧医院影像`、`5G医疗健康`、`5G+医疗健康`、`医疗健康专线`、`5G智慧园区`、`5G网络建设`、`5G物联网`、`5G智慧办公`、`5G信号覆盖`、`5G网络服务`、`5G专网安全`、`5G项目运维`、`5G农普`、`5G网络布局`。

关键词分三层使用：

- 明确网络证据：5G专网、5G工控专网、双域专网、软切片专网、UPF下沉、本地分流等。
- 网络别名线索：移动医护专网、无线生产网络、5G专线、APN专线等，需要结合正文。
- 行业场景线索：5G医学影像、5G智慧园区、5G物联网、5G农普等；单独命中通常先标为`待核实`，不直接认定为专网建设。

正文判断前会统一全半角、大小写和常见连接符，因此`5Ｇ`、`5g`、`5G＋医疗健康`等写法可以按统一规则识别。只在供应商业绩、历史案例或泛化背景中出现5G的项目应排除。

## 安装与运行

要求：Node.js 22.5或更高版本、pnpm 9或更高版本。Windows和macOS均可运行；SQLite使用Node内置模块，不需要另装数据库。

```bash
pnpm install

# 默认采集四川省从2026-01-01至当前时间
pnpm collect

# 明确指定开始日期，并扩大支持分页来源的翻页范围
pnpm collect --start-date 2026-01-01 --max-pages 5

# 临时只看近30天；该参数覆盖配置中的默认开始日期
pnpm collect --days 30

# 固定“当前日期”，便于重复验证
pnpm collect --as-of 2026-11-23

# 不联网，仅从现有SQLite重新导出默认日期窗口
pnpm export

# 核验用户提供的37条四川历史项目
pnpm audit:historical

# 从真实网页重新验证雅安已知样本
pnpm validate:sample

# TypeScript类型检查＋49项解析、分类、范围及来源分层测试
pnpm check
```

常用参数：

- `--start-date YYYY-MM-DD`：指定采集开始日期。
- `--days 30`：改用最近N个北京时间自然日。
- `--max-pages 2`：支持分页的平台每个查询组合最多读取的页数。
- `--output 文件.xlsx`：指定Excel输出位置。
- `--no-official-search`：跳过中国政府采购网国家站。
- `--no-sichuan-ccgp`：跳过四川政府采购网。
- `--no-ggzy`：跳过全国公共资源交易平台。
- `--no-sichuan-ggzy`：跳过四川省公共资源交易信息网。
- `--no-tianfu`：跳过天府阳光和四川能源天府阳光。
- `--no-telecom`：跳过中国电信阳光采购网。
- `--no-public-search`：跳过Bing公开搜索补充。

`pnpm validate:sample`会联网读取真实公告，核对解析器能否正确取出项目编号、采购人、预算和截止时间。`pnpm check`不做采集，它检查代码能否通过类型检查和自动化测试。

在Windows中，如果历史核验Excel正被打开，`pnpm audit:historical`会自动另存一个带时间戳的新文件，不会覆盖正在查看的文件。

## Excel内容

日常采集Excel包含四张表：

1. `监测清单`：明确相关和待核实项目。
2. `未纳入候选`：被排除的候选及理由，用于检查误判。
3. `运行与覆盖`：每个来源的实际范围、查询数、页数、候选数、状态和限制。
4. `字段说明`：相关性、截止状态、金额和日期字段定义。

主表只展示通过四川范围复核的记录。SQLite会保留不同来源的原始记录，导出时再进行跨平台合并。

## 数据、去重与运行状态

- SQLite唯一键为“来源详情URL＋标包”，重复运行不会重复入库。
- 不同平台的同一项目按“项目编号＋阶段＋标包”合并，并保留来源平台和备用链接。
- 预算、最高限价和中标/成交金额分开保存，不互相代填。
- 获取文件截止和投标/响应截止分别保存、分别计算状态。
- 更正公告优先按项目编号关联，以已核实的最新截止时间为准。
- `runs`、`provider_runs`和`source_status`记录每次运行及各来源状态。

状态含义：

- `success`：启用来源、详情抓取和导出均完成。
- `success_zero`：来源完整执行，但没有找到候选。
- `partial`：已取得有效结果，但某些来源受限、截断或部分详情失败。
- `failed`：没有取得可用详情，或数据库/导出等关键步骤失败。

## 当前限制

- 中国政府采购网和全国公共资源交易平台可能限频或触发验证码。
- 四川政府采购网免验证码接口每个关键词最多40条且不能可靠翻页。
- 天府阳光两站当前环境触发IP/滑块限制。
- 中国电信目前主要依赖标题检索，标题泛化且5G要求只在附件中的项目可能漏检。
- 当前只读取HTML/接口正文并枚举附件名称，尚未系统解析PDF、Word和图片公告。
- 采购人官网只用于线索发现和原文核验，不计入招标发布平台覆盖；小额院内采购可能没有同步平台。
- 集团采购和附件型项目正在按已验证平台逐步接入；`verified_pending`不等于日常采集已覆盖。
- 默认翻页有上限，Excel“运行与覆盖”记录的是本次实际范围，不能理解为全网无限覆盖。
